# 🎯 AimSync Pro — Cross-Device Touch & Gyro Calibrator for BGMI

**AimSync Pro** is an Android utility designed to bridge the touch-response and acceleration curve gap between **ColorOS / realme UI (Oppo, realme)** and **Funtouch OS / OriginOS (Vivo, iQOO)**.

### 🛡️ 100% Anti-Cheat Safe
- **Zero Memory Injection:** Does not hook, modify, or overlay on top of game binaries.
- **Hardware & Math Driven:** Uses screen DPI normalization, acceleration curve compensation, and Android `SensorManager` zero-drift calibration.

### ✨ Features
- **Touch-Curve Sensitivity Converter:** Converts iQOO/Vivo linear sensitivity values to compensate for ColorOS/realme UI's acceleration curve.
- **Real-Time Hardware Gyroscope Stabilizer:** Measures sensor bias and eliminates micro-jitter before gaming sessions.
- **Live Touch Sampling & Refresh Rate Monitor:** Measures real-time screen touch polling rate (Hz).
- **Safe System Optimization:** One-tap access to pointer speed, touch latency settings, and DND gaming focus.
